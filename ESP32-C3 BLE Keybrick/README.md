# ESP32-C3 BLE Keybrick — 五键 BLE 宏键盘

## 工程用途

提供蓝牙键盘、OLED 状态显示、电池检测、倒计时和节拍器；接线和操作详见下方原说明。

## 开发环境与使用

- 板型：esp32-c3-devkitm-1
- 在本目录执行 `pio run` 编译、`pio run -t upload` 烧录、`pio device monitor` 查看串口。依赖与板型以 platformio.ini 为准。
- 本次整理依据源码与配置，未执行固件编译或硬件测试。不同工程的引脚配置不通用，连接前核对各自源码。

## 硬件说明

```
        ┌─────────────────────┐
        │                     │
        │   [K1] [K2] [K3]   │    K1~K5: 5个功能按键
        │                     │
        │      [K4] [K5]      │    OLED: 128x32 显示屏
        │                     │
        │   ┌──────────────┐  │    LED: 状态指示灯
        │   │    OLED      │  │    Buzzer: 蜂鸣器
        │   └──────────────┘  │
        │      LED ●          │
        └─────────────────────┘
```

**MCU**: ESP32-C3 (esp32-c3-devkitm-1)

**引脚分配**:

| 引脚 | 功能 | 说明 |
|------|------|------|
| A0 | ADC_PIN | 电池电压检测 |
| GPIO1 | BUZZER_PIN | 蜂鸣器 |
| GPIO2 | BTN_1_PIN | 按键 1 |
| GPIO3 | BTN_2_PIN | 按键 2 |
| GPIO4 | BTN_3_PIN | 按键 3 |
| GPIO5 | BTN_4_PIN | 按键 4 |
| GPIO6 | OLED_SDA | I2C 数据 |
| GPIO7 | OLED_SCL | I2C 时钟 |
| GPIO8 | BTN_5_PIN | 按键 5 |
| GPIO10 | STATUS_LED | 状态指示灯 |

## 蓝牙配对

1. 接通电源，设备自动启动并进入广播模式
2. 状态 LED 开始 1Hz 闪烁 (每秒闪1次)，表示等待连接
3. 在电脑/手机的蓝牙设置中搜索并配对 `ESP32C3 BLE Keybrick`
4. 配对成功后 LED 变为常亮，OLED 显示 **"Connected"**

> 设备支持蓝牙配对绑定 (Bonding)。若断开连接，需要在系统蓝牙设置中手动重新连接。

## 系统模式

Keybrick 有 **4 种工作模式**，通过长按 K4 和 K5 切换 (长按约 2 秒以上):

```
                    ┌──────────────┐
         长按K5 ──>│  定时器设置    │
         (单独)    │ TIMER_SET    │
                    └──────┬───────┘
                           │ 长按K5 返回
                           ▼
                    ┌──────────────┐
    长按K4+K5 ──>│              │<── 长按K4 (单独)
    (同时按)     │   普通模式    │
                  │  MODE_NORMAL │──> 节拍器模式
                  └──────────────┘    METRONOME
                           │
                           │ 长按K4+K5 (同时按)
                           ▼
                    ┌──────────────┐
                    │  按键配置     │
                    │ KEY_CONFIG   │
                    └──────────────┘
```

| 操作 | 当前模式 | 目标模式 |
|------|---------|---------|
| 长按 K5 (单独) | 普通模式 | 定时器设置 |
| 长按 K5 (单独) | 定时器/节拍器/配置 | 返回普通模式 |
| 长按 K4 (单独) | 普通模式 | 节拍器模式 |
| 同时长按 K4+K5 | 普通模式 | 按键配置 |

---

## 普通模式 (MODE_NORMAL)

此模式下，5 个按键通过蓝牙发送预设的快捷键。

### 内置预设列表

设备内置 **6 组预设**，可在配置模式中切换:

| 编号 | 名称 | K1 | K2 | K3 | K4 | K5 |
|-----|------|-----|-----|-----|-----|-----|
| 1 | Zoom ANYV | Ctrl+Alt+A | Ctrl+Alt+N | Ctrl+Alt+Y | Ctrl+Alt+V | Alt+Shift+6 |
| 2 | Ctrl CVX | Ctrl+C | Ctrl+V | Ctrl+X | N/A | N/A |
| 3 | Win Combos | Alt+Tab | Win+D | Ctrl+Alt+Del | N/A | N/A |
| 4 | VSCode | 注释 (Ctrl+K+C) | 取消注释 (Ctrl+K+U) | 左对齐 (Ctrl+[) | 右对齐 (Ctrl+]) | N/A |
| 5 | LCEDA Tools | Alt+W (布线) | Alt+V (过孔) | Alt+E (覆铜) | Alt+T (顶层) | Alt+B (底层) |
| 6 | MediaCtrls | 音量+ | 音量- | 亮度+ | 亮度- | N/A |

> **注意**: 第 6 组预设 (MediaCtrls) 的亮度控制目前不可用。

### OLED 显示

```
┌────────────────────────────────┐
│ ██████ Title Logo ████████████ │  顶部标题栏
│ 📶 Connected     🔋 100%      │  蓝牙状态 + 电量
│ Key1: Ctrl+Alt+A              │  当前按键描述 (每2秒滚动)
│                                │
└────────────────────────────────┘
```

### 屏幕省电

- **20 秒**无操作 → 屏幕降低亮度
- **30 秒**无操作 → 屏幕自动关闭
- 任意按键操作 → 屏幕重新点亮

### 定时器显示

定时器启动后，普通模式底部额外显示:

```
TIM remaining: 00:05
```

## 定时器设置 (MODE_TIMER_SET)

进入方式: **普通模式下长按 K5**

### 按键功能

| 按键 | 功能 |
|------|------|
| K1 | 小时 +1 (0~23 循环) |
| K2 | 分钟 +1 (0~59 循环) |
| K3 | 启动定时器 (自动返回普通模式) |
| K4 | 重置 (归零并取消) |

### 操作步骤

1. 长按 K5 进入定时器设置
2. 按 K1 设置小时，按 K2 设置分钟
3. 按 K3 启动倒计时，自动返回普通模式
4. 倒计时结束后，蜂鸣器播放旋律提醒
5. **按下 K5 停止蜂鸣器**
6. 按 K4 可随时重置定时器

### OLED 显示

```
┌────────────────────────────────┐
│ > Timer Settings               │
│  <00:05>         00:04[ON]     │  设置时间 + 剩余时间
│                   Cnt Down     │
│ 1|HH 2|MM 3|En 4|Rst          │  操作提示
└────────────────────────────────┘
```

## 节拍器 (MODE_METRONOME)

进入方式: **普通模式下长按 K4**

### 按键功能

| 按键 | 功能 |
|------|------|
| K1 | BPM -1 (最低 40) |
| K2 | BPM +1 (最高 240) |
| K3 | 切换拍号 (1/4 → 2/4 → ... → 8/4 循环) |
| K4 | 开始/停止 |

### 操作步骤

1. 长按 K4 进入节拍器模式
2. 按 K1/K2 调节速度 (BPM)
3. 按 K3 切换拍号
4. 按 K4 开始/停止节拍
5. 运行时: 每拍蜂鸣器响一声，强拍 (第一拍) 额外闪烁 LED 并使用高音 (880Hz)，弱拍使用低音 (440Hz)
6. 长按 K5 返回普通模式

### OLED 显示

```
┌────────────────────────────────┐
│ > Metronome                    │
│ BPM:120 SIG:4/4               │  速度 + 拍号
│                                │
│ 1|- 2|+ 3|Sig 4|[RUN]         │  操作提示 + 运行状态
└────────────────────────────────┘
```

---

## 按键配置 (MODE_KEY_CONFIG)

进入方式: **普通模式下同时长按 K4+K5**

### 按键功能

| 按键 | 功能 |
|------|------|
| K1 | 上一组预设 |
| K2 | 下一组预设 |
| K3 | 确认选择并保存 (蜂鸣器响一声) |

### 操作步骤

1. 同时长按 K4+K5 进入配置模式
2. 按 K1/K2 浏览预设，OLED 显示当前预设的名称和按键说明
3. 按 K3 确认选择，**预设会保存到闪存**，下次开机自动加载
4. 确认后自动返回普通模式

### OLED 显示

```
┌────────────────────────────────┐
│ > Config Mode          [1/6]  │  当前第几组/共几组
│  Tag: Zoom ANYV               │  预设名称
│ - Key1: Ctrl+Alt+A            │  按键描述 (每2秒滚动)
│ - Key2: Ctrl+Alt+N            │
└────────────────────────────────┘
```

---

## 电池管理

- 电量通过 OLED 右上角显示 (百分比)
- 电量每 1 分钟通过 BLE 上报给已连接的设备
- **低电量 (<3.6V)** 时屏幕自动降低亮度
- 电池电压范围: 3.3V (0%) ~ 4.2V (100%)

## 构建

本项目使用 **PlatformIO** 构建，基于 Arduino 框架。

```ini
[env:esp32-c3-devkitm-1]
platform = espressif32
board = esp32-c3-devkitm-1
framework = arduino
```

编译并烧录:

```bash
pio run -t upload
```

## 已知限制

1. **无法自动重连** — 蓝牙断开后需在系统设置中手动重连
2. **媒体键不可用** — 第 6 组预设 (MediaCtrls) 的亮度控制功能未实现
3. **定时器阻塞** — 定时器到时后蜂鸣器会阻塞操作，必须按 K5 停止
4. **屏幕自动关闭** — 30 秒无操作屏幕会关闭，按任意键唤醒
