# ESP32TFT-main — Arduino TFT 学习示例合集

## 工程用途

原始示例在 ESP32TFT-main 子目录：点亮 TFT、图形动画、中文多字体、图片、SD 卡 JPEG 相册、时钟、无牙仔 Wi-Fi 时钟、旋转立方体及字符雨；附 Python 字体和 RGB565 转换工具、图片及库压缩包。每个 .ino 示例单独打开，按相应 readme 和 User_Setup 配置 TFT_eSPI 与接线；没有统一 PlatformIO 配置。保留原作者说明及已有许可证，未额外声明整库许可证。

## 开发环境与使用

- 板型：ESP32 / Arduino IDE
- 用 Arduino IDE 分别打开示例。原教程位于 ESP32TFT-main/README.md。
- 本次整理依据源码与配置，未执行固件编译或硬件测试。不同工程的引脚配置不通用，连接前核对各自源码。
